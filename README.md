# 神狩荘 怪異・現象候補一覧

## GitHubへのアップロード

次の4ファイルを、同じ階層（リポジトリの一番上）へ置いてください。

- `index.html`：ページの構成
- `style.css`：色・枠・文字・スマホ表示
- `script.js`：一覧の表示・検索・番号や件数の自動更新
- `data.js`：怪異の本文。普段はこのファイルだけ編集します。

既存の `index.html` は、この新しいファイルで置き換えます。
フォルダーごとアップロードせず、フォルダー内の4ファイルをアップロードしてください。
GitHub Pagesがすでに有効なら、コミット後に更新が反映されます。

## 怪異を追加する

GitHubで `data.js` を開き、鉛筆の編集ボタンを押します。
`items: [` の中にある怪異のかたまりをコピーして、末尾の `],` の直前へ追加します。
各かたまりの最後は `},` にしてください。

```javascript
    {
      area: "courtyard",
      title: "新しい怪異の名前",
      location: "中庭のどこか",
      paragraphs: [
        "最初の段落。",
        "次の段落。",
      ],
    },
```

`area` を変えると、その場所に自動で分類されます。

| area | 表示場所 |
| --- | --- |
| `courtyard` | 中庭 |
| `backyard` | 裏庭 |
| `entrance` | 玄関・外周 |
| `indoor` | 廊下・屋内 |
| `stair` | 外階段・屋上 |

番号・全件数・場所別の件数は自動計算されます。数字を書き直す必要はありません。
表示は場所別で、同じ場所の中では `items` に記載した順番になります。
途中に追加した場合は、それ以降の番号が変わります。

## 本文を修正する・削除する

- 名前を変える：`title` の文章を変更します。
- 場所を変える：`area` と `location` を変更します。
- 本文を変える：`paragraphs` の文章を変更します。
- 段落を増やす：`paragraphs` の中へ `"文章",` を追加します。
- 怪異を削除する：その怪異の `{` から `},` までを削除します。

文章を囲む半角の `"` と、末尾の半角カンマ `,` は残してください。
文章中の引用には「」を使うと、編集しやすくなります。
文章中に半角の `"` を使う場合は `\"` と書きます。
HTMLタグやMarkdownの記号は不要です。本文は普通の文章として表示されます。

## 場所の区分を増やす

`data.js` の `areas` に、例えば次を追加します。

```javascript
    { id: "well", name: "井戸周辺" },
```

その場所の怪異では `area: "well"` と書きます。
`id` は半角英数字・ハイフン・アンダースコアで、他の場所と重複しない名前にしてください。
場所の目次も自動で増えます。

## ページの紹介文を変更する

タイトル・紹介文・方針は `index.html` にあります。
怪異の本文は `data.js`、デザインは `style.css` にあります。

## 手元で確認する

4ファイルを同じフォルダーに置いて、`index.html` をブラウザで開けます。
画像や外部ライブラリ、サーバー、アカウント情報は使用していません。
