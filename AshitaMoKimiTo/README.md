# 神狩荘 常設シナリオ「明日も君と」試作版

## 公開方法

1. GitHub の `kagariso` リポジトリを開く。
2. `AshitaMoKimiTo` フォルダを作り、`index.html`, `style.css`, `data.js`, `app.js` を同じ階層にアップロードする。
3. GitHub Pages が `main / root` で公開されている場合、`https://jellyfish-free.github.io/kagariso/AshitaMoKimiTo/` が公開予定 URL。
4. iPhoneなどのブラウザで開き、BANDでのRPを進めながら代表者が操作する。

## 動作
- 初日：六つのシーンを読み自由RP。神社の絵馬の願いが事件の発端。
- ループ後：午前・午後・夕方にそれぞれ1項目、合計3項目を探索。全32項目。
- 5回のループ、百合の花弁の段階的黒化。
- お守りの入手・奉納、山羊との対話・戦闘表現・逃走・投擲。
- END A / B / C と神狩荘版未解決END D。
- localStorageに自動保存。JSONセーブのエクスポート・インポート対応。

## 重要な注意
- **これは試作版です**。本シナリオの元ログと作者の構想に基づきつつ、新設の探索項目や補助描写、シナリオ進行を補筆しています。作者確定部分とは区別して調整してください。
- `data.js` や `app.js` のソースは閲覧可能なため、厳密なネタバレ防止には対応していません。
- **複数端末の自動同期はありません**。代表者の端末のセーブが進行データになります。
- ブラウザデータを削除するとセーブも消えます。必要に応じてJSON形式で書き出してください。
- KPCの記憶をリセットするのは物語上の設定です。参加者本人は情報を知っていても、役割に応じてRPしてください。
- 原作にはロストがありますが、神狩荘版では世界線の追体験とし、住人は永続ロストしません。

## 要調整候補
- 初日の自由探索を選択できるよう拡張する。
- 詳細描写・画像・サウンドの追加。
- 実際の二人のRPに合わせた進行役向け操作画面。
- D1を使った二端末共有セッション。

## ネタバレ防止
- スタート画面、遊び方、初日のシーンには「誰が記憶を失うか」「ループ開始」などの情報を表示しません。
- 初日の絵馬は参加者②が書きます。異変は翌朝の演出で初めて明かされます。
- **READMEとソースコードは制作者向け**です。プレイヤーにはWebアプリのURLだけを案内してください。

## 加筆・修正する場合

- **data.js**：初日のシーンと32件の探索描写。`intro` と `clues` を編集します。
- **app.js**：ボタン、探索枠、ループ、お守り、エンディングの条件や文章。
- **style.css**：背景色、文字の大きさ、余白、各ボタンの見た目。
- **index.html**：タイトル・読み込み順序などページの基本構造。

各ファイルには日本語の説明コメントを記載しています。描写の文章は
`data.js` の各項目で複数行に分け、文末の `+` で接続しています。
`+` を削除すると構文エラーになるので注意してください。

**ネタバレ注意：** 初日用の `intro` にループや記憶喪失の真相を
追加しないでください。最初のループ開始場面で初めて開示します。

**セーブ互換性：** `clues` の項目を並べ替えると、すでに保存された
探索済み情報とズレる場合があります。新項目は末尾への追加を推奨します。
